# IMS — Inventory Management System
> ASP.NET Core Blazor · EF Core · SQL Server · Identity

## Overview
IMS is a full-featured **Inventory Management System** built with ASP.NET Core Blazor. It covers product tracking, stock management, and user authentication via ASP.NET Identity.

## Features
- Product and inventory tracking
- User authentication and role-based access control via ASP.NET Identity
- Real-time UI updates with Blazor
- Full CRUD operations backed by EF Core and SQL Server

## Tech Stack
- ASP.NET Core Blazor
- Entity Framework Core
- SQL Server
- ASP.NET Identity

## Getting Started
```bash
git clone https://github.com/OrlandoMalo505/IMS
cd IMS
dotnet restore
dotnet run
```
